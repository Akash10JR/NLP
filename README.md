## 📌 Sections Overview

- **Unit 1 to Unit 5**: Contains unit-wise assessments (`Assessment-1`, `Assessment-2`, `Assessment-3`).
- **Capstone Project**: 
  - `Datasets`: Raw and processed project datasets.
  - `PPT`: Presentation slides.
  - `Reports`: Project documentation and reports.
  - `Source Code`: Implementation code and models.
- **Assignments**: Coursework submissions and assignments.
- **Certificates**: Course completion and achievement certificates.
- **experiment**: Laboratory experiments and practical implementations.
